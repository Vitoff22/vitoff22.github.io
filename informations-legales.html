02

Confidentialité

Julien Fretille est responsable de l’utilisation des messages qu’il reçoit pour répondre aux demandes concernant ce portfolio, son parcours ou une opportunité professionnelle. Pour toute question ou demande relative à vos données, écrivez à julien.fretille@gmail.com.

Quand vous prenez contact

Le formulaire prépare un e-mail dans votre application de messagerie. Les champs sont traités dans votre navigateur et ne sont pas envoyés à un serveur du portfolio. Vous pouvez modifier, envoyer ou abandonner le message dans votre messagerie.

Le nom est facultatif ; un message est nécessaire pour préparer l’e-mail. Une fois l’envoi confirmé par vous, Julien reçoit votre adresse e-mail, votre message, ainsi que le nom et les éventuelles pièces jointes que vous choisissez de transmettre. Sans envoi, aucun message ne lui parvient par ce formulaire.

Pourquoi ces données sont utilisées

Elles servent à répondre à votre demande et à suivre l’échange. Ce traitement repose sur l’intérêt légitime de Julien Fretille à répondre aux personnes qui le contactent, dans les limites de leur attente et de leurs droits. Les messages ne sont pas réutilisés pour une newsletter, du profilage ou de la prospection automatisée.

Destinataires et services utilisés

Julien Fretille est le destinataire des messages. Votre fournisseur de messagerie et Gmail, utilisé pour recevoir les e-mails, interviennent dans leur acheminement et leur stockage. Les modalités de traitement de Google sont décrites dans sa politique de confidentialité (nouvel onglet)↗.

Conservation des échanges

Les messages sont conservés pendant le traitement de la demande et le suivi qui en découle. La clôture de la demande ou du processus de recrutement marque la fin de leur utilité, sauf si un échange reste nécessaire à une relation en cours, à une obligation légale ou à l’exercice ou la défense d’un droit. Seules les informations encore nécessaires sont alors conservées. Le site n’enregistre aucun historique de messages ; il n’effectue pas de suppression automatique dans la messagerie.

Données techniques d’hébergement

Lors d’une visite, GitHub Pages enregistre notamment l’adresse IP à des fins de sécurité, que le visiteur soit connecté à GitHub ou non. Julien ne dispose pas d’un outil d’analyse individuelle des visiteurs dans ce site. Les durées et modalités des journaux techniques relèvent de GitHub ; voir la politique de confidentialité GitHub (nouvel onglet)↗.

GitHub et Google peuvent traiter des données hors de l’Espace économique européen, notamment aux États-Unis. Leurs politiques décrivent les mécanismes de transfert applicables, dont les clauses contractuelles types et les cadres d’adéquation lorsqu’ils s’appliquent. Ce site ne garantit pas un hébergement ou un traitement exclusivement en France.

Vos droits

Selon les conditions prévues par le RGPD, vous pouvez demander l’accès, la rectification, l’effacement ou la limitation du traitement de vos données et vous opposer à un traitement fondé sur l’intérêt légitime. Une demande peut être adressée à l’e-mail ci-dessus. Si des éléments supplémentaires sont nécessaires pour vérifier votre identité, ils sont limités à ce besoin.

Une réponse est apportée dans le délai applicable, en principe un mois ; une prolongation motivée peut être nécessaire pour une demande complexe. Vous pouvez également adresser une réclamation à la CNIL (nouvel onglet)↗. Pour les données traitées directement par GitHub ou votre messagerie, leurs politiques précisent les contacts correspondants.

03

Cookies & stockage local

Le code de ce portfolio ne dépose aucun cookie publicitaire et n’intègre aucun outil de mesure d’audience. Les polices, illustrations et fichiers du site sont hébergés avec le portfolio, sans chargement de police ni de média intégré depuis un service tiers.

Information conservée
portfolio:intro-seen, avec la valeur 1, dans le stockage de session de l’onglet (sessionStorage).
Utilité
Éviter de rejouer l’animation d’introduction pendant la même session de navigation. Cette valeur ne contient aucun identifiant personnel ni contenu du formulaire et n’est pas transmise à un serveur.
Durée
La session de l’onglet, gérée par votre navigateur. Une restauration de session peut également restaurer cette information.

Ce stockage est utilisé uniquement pour cette fonction d’interface. Aucun bandeau de consentement publicitaire n’est affiché. Si le stockage est bloqué par votre navigateur, l’introduction est simplement ignorée et le portfolio reste consultable.

Les boutons « Copier » écrivent uniquement l’adresse e-mail ou le lien du projet dans le presse-papiers après votre clic. Ils ne lisent pas son contenu. Vous pouvez aussi mettre les animations en pause ; la préférence de réduction des mouvements de votre navigateur est respectée.
